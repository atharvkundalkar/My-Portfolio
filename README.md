# Atharv Kundalkar | Professional Portfolio

Welcome to my personal portfolio website. This project showcases my journey as a Software Developer, featuring a premium, high-end design with modern web technologies.

## 🚀 Live Demo

[**View Live Portfolio**](https://atharvkundalkar.github.io/My-Portfolio/)

## 🎨 Features

- **Premium Design**: Modern "Glassmorphism" aesthetic with a cinematic dark theme.
- **Interactive UI**:
  - Ambient background lighting effects.
  - Smooth ScrollReveal animations.
  - Dynamic text typing effects.
- **Fully Responsive**: Optimized for all devices from mobile to desktop.
- **Custom Assets**: Grain texture overlays and refined typography (Outfit font).

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Libraries**:
  - [ScrollReveal](https://scrollrevealjs.org/) (Scroll animations)
  - [Typed.js](https://github.com/mattboldt/typed.js/) (Typing effect)
  - [Boxicons](https://boxicons.com/) (Icons)
